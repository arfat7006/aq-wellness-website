# AQ Wellness & Aesthetics Centre Website

A responsive static website for AQ Wellness & Aesthetics Centre.

## Files
- `index.html` — website content
- `styles.css` — layout and visual styling
- `script.js` — mobile menu, WhatsApp button and Google Maps link

## Before publishing
1. Open `script.js`.
2. Replace `91XXXXXXXXXX` with the clinic's WhatsApp number (country code + number, digits only). Example format: `919876543210`.
3. Review the services and contact details in `index.html`.

## Deploy on Netlify
This is a plain HTML/CSS/JavaScript website. In Netlify build settings:
- Branch: `main`
- Base directory: leave blank
- Build command: leave blank
- Publish directory: `.`

Then deploy. The website files must be present in the root of the GitHub repository.
